# Frontend

Frontend — React 18 SPA на TypeScript и Vite. Маршрутизация выполняется React Router, production-ресурсы собираются Vite и отдаются Nginx.

## Маршруты

| URL | Назначение |
| --- | --- |
| `/` | главная и сценарий цифрового потока |
| `/services`, `/services/:slug` | каталог и карточка услуги |
| `/cart`, `/request`, `/request/success/:number` | расчёт и оформление |
| `/track` | проверка заявки |
| `/about` | границы и назначение MVP |
| `/admin/login` | вход администратора |
| `/admin`, `/admin/orders/:id` | очередь, метрики и заявка |
| `/admin/services`, `/admin/assistant` | каталог и read-only помощник |

## Состояние

- `CartContext` хранит уникальные позиции корзины в `localStorage` под ключом `sk-cart`. Повторное добавление увеличивает количество, максимум — `10000`, минимум — `0.1`.
- `AssistantChat` хранит conversation id, selection, текущий расчёт и состояния действий под ключом `sk-assistant-selection-v1`.
- `ToastContext` показывает до трёх уведомлений, устраняет дубликаты и использует live-region.
- Серверные данные запрашиваются через единый `api()` с `credentials: include` и нормализованной обработкой ошибок.

## Доверенные и недоверенные данные

Корзина и состояние чата в браузере удобны для UX, но не доверяются сервером. Цена пересчитывается через `/quotes`; при оформлении сервер выполняет расчёт ещё раз. ИИ-кнопка валидирует активность услуги, единицу, количество, цену и итог до изменения корзины.

Markdown ответов рендерится `react-markdown` с `remark-gfm`; сырой HTML не включён. Навигация из ответа ограничивается данными, которые возвращает backend.

## Сборка

Команда `npm run build` последовательно выполняет TypeScript project build и Vite production build. Nginx использует `try_files ... /index.html`, поэтому прямое открытие SPA-маршрутов работает.
