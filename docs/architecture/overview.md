# Обзор архитектуры

Система состоит из React SPA, FastAPI API, SQLite и необязательного OpenAI-compatible LLM. Nginx публикует единственный порт `8080`: статические файлы отдаёт сам, а `/api/*` проксирует в backend. Это сохраняет same-origin модель для браузера и admin cookie.

## Компоненты

| Компонент | Ответственность | Источник истины |
| --- | --- | --- |
| React + TypeScript | интерфейс клиента и администратора, локальное состояние корзины и чата | серверные ответы для цен, услуг и статусов |
| Nginx | SPA fallback и reverse proxy `/api/` | `frontend/nginx.conf` |
| FastAPI | валидация, бизнес-правила, авторизация, расчёты, orchestration ИИ | backend-код и БД |
| SQLAlchemy + Alembic | модель и миграция данных | SQLite volume |
| SQLite | каталог, заявки, позиции, история, администратор | `/data/stroykompleks.sqlite3` в контейнере |
| LLM | только формулировка ответа | не управляет ценами, корзиной или заявками |
| Docker Compose | локальная и серверная сборка | `docker-compose.yml` |

## Основные принципы

1. Backend всегда повторно рассчитывает стоимость по активному каталогу.
2. В заявку записываются snapshots названия, единицы, цены и суммы; последующее изменение каталога не меняет историю.
3. ИИ-действия формируются и проверяются сервером. Перед изменением корзины frontend повторно запрашивает каталог и `/quotes`.
4. Публичное отслеживание требует одновременно номера заявки и телефона.
5. Административные операции защищены подписанной HttpOnly cookie и origin-проверкой для изменений.
6. При недоступной LLM система возвращает детерминированный demo-ответ и продолжает работать.

## Потоки данных

- Каталог: браузер → `GET /services` → SQLAlchemy → SQLite.
- Корзина: `localStorage` → `POST /quotes` → актуальные серверные цены.
- Заявка: форма + `Idempotency-Key` → серверный перерасчёт → заказ и snapshots → публичный номер.
- ИИ: сообщение + история + корзина + selection → детерминированный разбор → необязательная LLM → проверенные действия.
- Администрирование: cookie-сессия → фильтры/изменения → история статусов и метрики.
