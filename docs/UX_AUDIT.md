# UX-аудит визуальной обратной связи

Дата: 27.10.2026. Ветка: `feat/ux-feedback`.

| Зона | Обнаруженный разрыв | Реализованная обратная связь |
| --- | --- | --- |
| Каталог и карточка услуги | Добавление проходило без подтверждения, повторное добавление было неочевидно | Success toast с названием услуги; отдельное сообщение при обновлении количества |
| Детальная страница | Некорректный объём только блокировал кнопку | Inline-ошибка, `aria-invalid`, живой предварительный итог |
| Корзина | Пересчёт был неотличим от зависания, удаление — без подтверждения результата | Индикатор «Пересчитываем стоимость…», error state/toast, уведомления удаления и очистки |
| Очистка корзины | Использовался системный `confirm` | Доступное модальное подтверждение с явными действиями |
| Оформление | Только браузерная валидация; новый ключ при каждом повторе | Inline-ошибки, loading «Отправка заявки…», стабильный idempotency-key, данные сохраняются при ошибке |
| Поиск заявки | Слабое состояние ожидания | Loading «Поиск заявки…», блокировка повторной отправки, результат остаётся главным подтверждением |
| Вход и выход администратора | Не было глобального подтверждения | Loading, inline error, success/info/error toast |
| Заявка в админке | Ложное сохранение без изменений было возможно | Кнопка заблокирована без изменений; отдельные toast для статуса и комментария; история обновляется из ответа API |
| Управление услугами | CRUD и активация проходили без подтверждения | Loading и тематические toast для создания, редактирования цены, активации и ошибок |
| Помощники | Общий текст ожидания и тихие ошибки | Контекстные loading-сообщения, ошибки в чате и toast; добавление рекомендации подтверждается |
| Глобальная доступность | Не хватало единого фокуса, reduced motion и live-region | `focus-visible`, `aria-live`, роли alert/status, reduced-motion, максимум три toast и дедупликация |

Toast намеренно не используется для фильтров, поиска по каталогу, открытия страниц и других действий без серверной мутации или значимого результата.
