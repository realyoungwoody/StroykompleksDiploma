# Каталог услуг

Публичный каталог показывает только активные услуги, отсортированные по `sort_order` и названию. Начальный seed содержит восемь позиций: два вида штукатурки, два вида покраски, настенную и напольную плитку, натяжной потолок и ламинат.

## Данные услуги

Услуга включает slug, название, категорию, краткое и полное описание, этапы, единицу измерения, базовую цену, признак активности и порядок. Slug допускает только латинские строчные буквы, цифры и дефис.

Публичные endpoints:

- `GET /api/v1/services` — активный каталог;
- `GET /api/v1/services/{slug}` — активная услуга или 404;
- `GET /api/v1/faq` — 12 демонстрационных вопросов.

## Администрирование

Авторизованный администратор видит и неактивные услуги, может создать услугу или частично изменить существующую. Физического удаления нет: для сохранения исторической целостности позицию следует деактивировать.

Изменение цены влияет на новые расчёты, но не меняет snapshots ранее созданных заявок. Уникальность slug проверяется БД; конфликт возвращает HTTP 409.

## Ограничения

Изображения, материалы, скидки, региональные цены и сложные тарифные сетки не моделируются. Цена линейна: `количество × базовая цена`.
